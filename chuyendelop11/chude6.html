Tập Dữ liệu mẫu: Quản lý Trường học

Để dễ hình dung, chúng ta sẽ thực hành xây dựng hệ thống gồm 2 bảng có quan hệ 1-N (Một Lớp có Nhiều Học sinh):

Bảng 1: LOPHOC (Lớp học - Bảng Cha)

idLop (Khóa chính)tenLopphongHoc
111A2Phòng 301
211A5Phòng 302

Bảng 2: HOCSINH (Học sinh - Bảng Con)

idHS (Khóa chính)hoTenngaySinhidLop (Khóa ngoại)
1Nguyễn Hoàng Bảo2009-05-121 (11A2)
2Lê Văn Tuấn2009-11-052 (11A5)

Bài 17, 18, 19: Thao tác tạo lập CSDL và bảng LopHoc

Chúng ta sử dụng phần mềm HeidiSQL để khởi tạo CSDL bằng các thao tác click chuột trực quan.

Bước 1: Tạo Cơ sở dữ liệu (Database)
  1. Mở HeidiSQL và kết nối vào hệ thống.
  2. Ở khung bên trái, nhấp chuột phải vào dòng kết nối (ví dụ: Unnamed).
  3. Chọn Tạo mới (Create new) → Chọn Cơ sở dữ liệu (Database).
  4. Nhập tên là QL_TruongHoc.
  5. Mục Collation, bắt buộc chọn utf8mb4_unicode_ci (để gõ được tiếng Việt). Nhấn OK.
Bước 2: Tạo Bảng Cha (LopHoc)
  1. Nhấp chuột phải vào CSDL `QL_TruongHoc` vừa tạo.
  2. Chọn Tạo mới → Chọn Bảng (Table). Đặt tên bảng là LopHoc.
  3. Sang tab Cột (Columns), nhấn nút Thêm (Add) để tạo 3 trường:
    - `idLop` (Kiểu: INT). Tick chọn ô Auto_increment.
    - `tenLop` (Kiểu: VARCHAR, Độ dài: 50).
    - `phongHoc` (Kiểu: VARCHAR, Độ dài: 50).
  4. Tạo Khóa chính: Nhấp chuột phải vào cột `idLop` → Chọn Tạo chỉ mục mới → Chọn PRIMARY.
  5. Nhấn nút Lưu (Save) trên thanh công cụ.

Bài 20: Tạo bảng HocSinh và thiết lập Khóa ngoại

Bước 3: Tạo Bảng Con và Khóa Ngoại (Foreign Key)
  1. Làm lại thao tác tạo bảng mới, đặt tên là HocSinh.
  2. Thêm 4 cột: `idHS` (INT, Auto_increment, gán PRIMARY KEY), `hoTen` (VARCHAR 100), `ngaySinh` (DATE), `idLop` (INT).
  3. Chuyển sang thẻ Khóa ngoại (Foreign keys) nằm ngay cạnh thẻ Cột. Nhấn Thêm (Add).
  4. Thiết lập ràng buộc:
    - Cột tham chiếu: Tick chọn `idLop` (của bảng HocSinh).
    - Bảng tham chiếu: Chọn bảng `LopHoc`.
    - Cột đích: Chọn `idLop` (của bảng LopHoc).
  5. Nhấn nút Lưu (Save).

Bài 21 & 22: Thao tác nhập liệu trực tiếp

Lưu ý cực kỳ quan trọng: Phải nhập dữ liệu cho bảng `LopHoc` trước, bảng `HocSinh` sau.

Bước 4: Nhập liệu vào hệ thống
  1. Nhấp đúp chuột vào bảng LopHoc ở khung bên trái.
  2. Nhìn sang khung bên phải, chọn thẻ Dữ liệu (Data).
  3. Nhấn biểu tượng dấu cộng màu xanh (+) hoặc phím Insert để thêm hàng.
  4. Cột `idLop` bỏ trống (vì máy tự nhảy số). Cột `tenLop` gõ `11A2`, cột `phongHoc` gõ `Phòng 301`. Nhấn Enter.
  5. Mở bảng HocSinh và làm tương tự. Ở cột `idLop`, bạn phải gõ đúng số `1` hoặc `2` để máy hiểu học sinh đó thuộc lớp nào.

Bài 23: 10 Ví dụ Truy xuất dữ liệu (Câu lệnh SQL)

Mở thẻ Truy vấn (Query) trên HeidiSQL để gõ và chạy (Run) các câu lệnh sau:

Ví dụ 1: Lấy toàn bộ dữ liệu lớp học

SELECT * FROM LopHoc;

Ví dụ 2: Chỉ lấy cột Họ tên và Ngày sinh

SELECT hoTen, ngaySinh FROM HocSinh;

Ví dụ 3: Lọc học sinh có họ "Nguyễn" (Toán tử LIKE)

SELECT * FROM HocSinh WHERE hoTen LIKE 'Nguyễn%';

Ví dụ 4: Tìm lớp học đang ở dãy phòng 300

SELECT tenLop, phongHoc FROM LopHoc WHERE phongHoc LIKE '%30%';

Ví dụ 5: Lọc các học sinh sinh nhật trong tháng 8

SELECT hoTen, ngaySinh FROM HocSinh WHERE MONTH(ngaySinh) = 8;

Ví dụ 6: Sắp xếp ngày sinh giảm dần (Trẻ nhất lên đầu)

SELECT hoTen, ngaySinh FROM HocSinh ORDER BY ngaySinh DESC;

Ví dụ 7: Lấy 2 học sinh đầu tiên trong bảng (Giới hạn dòng)

SELECT * FROM HocSinh LIMIT 2;

Ví dụ 8: INNER JOIN (Ghép Tên HS và Tên Lớp)

SELECT HocSinh.hoTen, LopHoc.tenLop FROM HocSinh INNER JOIN LopHoc ON HocSinh.idLop = LopHoc.idLop;

Ví dụ 9: Lấy danh sách chi tiết các học sinh đang học lớp 11A2

SELECT HocSinh.hoTen, LopHoc.phongHoc FROM HocSinh INNER JOIN LopHoc ON HocSinh.idLop = LopHoc.idLop WHERE LopHoc.tenLop = '11A2';

Ví dụ 10: Thống kê tổng số lượng học sinh của từng lớp (GROUP BY)

SELECT LopHoc.tenLop, COUNT(HocSinh.idHS) AS SoLuongHS FROM LopHoc LEFT JOIN HocSinh ON LopHoc.idLop = HocSinh.idLop GROUP BY LopHoc.tenLop;

BÀI TẬP THỰC HÀNH TỔNG HỢP

Bài tập 1: CSDL Quản lý Thư viện (`QL_ThuVien`)

Hệ thống gồm 2 bảng:
- TacGia: idTG (Khóa chính), tenTG
- Sach: idSach (Khóa chính), tenSach, namXB, idTG (Khóa ngoại)

Câu 1.1: Viết lệnh SQL thêm tác giả "Nam Cao" (có id = 1) và sách "Chí Phèo" (xuất bản 1941) của tác giả này.
INSERT INTO TacGia (idTG, tenTG) VALUES (1, 'Nam Cao'); INSERT INTO Sach (tenSach, namXB, idTG) VALUES ('Chí Phèo', 1941, 1);
Câu 1.2: Hiển thị danh sách các cuốn sách được xuất bản sau năm 2000.
SELECT * FROM Sach WHERE namXB > 2000;
Câu 1.3: Cập nhật đổi tên sách "Chí Phèo" thành "Chí Phèo - Tuyển tập".
UPDATE Sach SET tenSach = 'Chí Phèo - Tuyển tập' WHERE tenSach = 'Chí Phèo';
Câu 1.4: In ra màn hình Tên Sách, Năm XB và Tên Tác Giả bằng cách nối 2 bảng.
SELECT Sach.tenSach, Sach.namXB, TacGia.tenTG FROM Sach INNER JOIN TacGia ON Sach.idTG = TacGia.idTG;

Bài tập 2: CSDL Quản lý Bán hàng (`QL_BanHang`)

Hệ thống gồm 2 bảng:
- KhachHang: idKH (Khóa chính), tenKH
- DonHang: idDH (Khóa chính), ngayMua, tongTien, idKH (Khóa ngoại)

Câu 2.1: Lấy toàn bộ Đơn hàng, sắp xếp theo ngày mua giảm dần.
SELECT * FROM DonHang ORDER BY ngayMua DESC;
Câu 2.2: Đếm tổng số lượng đơn hàng đã được bán ra.
SELECT COUNT(idDH) AS TongSoDon FROM DonHang;
Câu 2.3: Hiển thị Tên khách hàng và Tổng tiền của các hóa đơn họ mua.
SELECT KhachHang.tenKH, DonHang.tongTien FROM DonHang INNER JOIN KhachHang ON DonHang.idKH = KhachHang.idKH;
Câu 2.4: Xóa vĩnh viễn thông tin Khách hàng có idKH = 5.
DELETE FROM KhachHang WHERE idKH = 5;
