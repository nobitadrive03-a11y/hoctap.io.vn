Bài 13. Vai trò của CSS (Cascading Style Sheets) trong thiết kế web.

1. Khái niệm mẫu định dạng CSS

CSS (Cascading Style Sheets) là ngôn ngữ được sử dụng để tìm và định dạng các phần tử hiển thị trên trang web; giúp tách biệt phần nội dung (viết bằng HTML) và phần trình bày (viết bằng CSS).

Đặc điểm:

  • Một mẫu định dạng có thể áp dụng cho hàng loạt phần tử trên một hoặc nhiều trang web.
  • CSS là ngôn ngữ mô tả kiểu dáng, độc lập với HTML.
  • Giúp thiết lập các thuộc tính như: màu sắc, phông chữ, kích thước, khung viền…

Nhận xét về mã nguồn: Trong HTML, các định dạng CSS nội bộ thường được đặt trong thẻ <style> nằm trong phần <head>. Các định dạng này được viết tập trung một chỗ và áp dụng tự động cho các thẻ tương ứng bên dưới phần <body>.

2. Cấu trúc CSS

Cấu trúc tổng quát của một mẫu định dạng CSS gồm hai phần chính: Bộ chọn (Selector) và Vùng mô tả (Declaration block).

Bộ chọn { thuộc tính : giá trị; }

Giải thích:

  • Bộ chọn: Xác định phần tử HTML nào sẽ chịu tác động của định dạng (ví dụ: h1, p, body…).
  • Vùng mô tả: Nằm trong cặp dấu ngoặc nhọn {}, bao gồm các khai báo. Mỗi khai báo gồm thuộc tính và giá trị, phân cách nhau bởi dấu hai chấm :, kết thúc bằng dấu chấm phẩy ;.

Ví dụ:

  • Đơn giản: h1 { color: red; } (Bộ chọn là thẻ h1, thuộc tính là color, giá trị là red).
  • Gộp nhóm: h1, h2, h3 { color: red; } (Áp dụng màu đỏ cho cả 3 loại thẻ tiêu đề).
  • Nhiều thuộc tính: p { text-indent: 15px; color: blue; } (Vừa thụt đầu dòng, vừa có màu chữ xanh).

3. Các cách thiết lập CSS

Có 3 phương pháp chính để chèn CSS vào trang web:

a) Cách thiết lập CSS trong (Internal CSS)

Toàn bộ mã CSS được đặt bên trong thẻ <style> ... </style>, thường nằm trong phần <head> của tệp HTML.

Ưu điểm: Phù hợp cho các trang web đơn lẻ, dễ quản lý khi trang web nhỏ.

b) Cách thiết lập CSS ngoài (External CSS)

Mã CSS được viết trong một tệp văn bản riêng biệt có đuôi mở rộng là .css (ví dụ: styles.css). Tệp HTML liên kết với tệp CSS này thông qua thẻ <link> đặt trong phần <head>.

<link href="styles.css" rel="stylesheet" type="text/css">

Ưu điểm: Tách biệt hoàn toàn nội dung và định dạng. Một tệp CSS có thể dùng chung cho cả website, giúp việc chỉnh sửa giao diện đồng bộ và nhanh chóng.

c) Cách thiết lập CSS nội tuyến (Inline CSS)

Định dạng trực tiếp trong thẻ HTML bằng thuộc tính style. Ví dụ: <h1 style="color: red;">Tiêu đề</h1>

Ưu điểm: Nhanh, tiện lợi để thử nghiệm hoặc sửa lỗi cục bộ.
Nhược điểm: Khó quản lý, mã nguồn rối, không tận dụng được khả năng tái sử dụng của CSS.

4. Vai trò, ý nghĩa của CSS

CSS đóng vai trò quan trọng trong phát triển web hiện đại:

  • Tách biệt nội dung và hình thức: Giúp mã nguồn HTML trong sáng, dễ đọc hơn.
  • Tiết kiệm thời gian và công sức: Viết CSS một lần và áp dụng cho nhiều trang. Khi cần thay đổi giao diện, chỉ cần sửa một tệp CSS duy nhất.
  • Tăng tốc độ tải trang: Trình duyệt có thể lưu bộ nhớ đệm (cache) tệp CSS, giúp tải các trang sau nhanh hơn.
  • Thống nhất giao diện: Đảm bảo sự đồng bộ về màu sắc, phông chữ trên toàn bộ website.
Tình huống vận dụng Bài 13 - Tình huống 1

Tình huống: Học sinh thắc mắc: "Ngôn ngữ CSS có phải là một phiên bản nâng cấp của HTML không? Các mẫu định dạng CSS thường được viết như thế nào?"

Trả lời khoa học: CSS không phải là HTML. CSS là một ngôn ngữ định dạng độc lập, có cú pháp riêng biệt so với HTML. Các mẫu định dạng CSS thường được mô tả trên nhiều hàng để dễ đọc và quản lý (tuy nhiên có thể viết trên một hàng). Cấu trúc thường bao gồm bộ chọn (Selector) và các thuộc tính nằm trong dấu ngoặc nhọn.

Tình huống vận dụng Bài 13 - Tình huống 2

Tình huống: Khi thiết kế trang web, nếu muốn thiết lập một mẫu CSS để áp dụng cho toàn bộ tệp HTML hiện tại thì làm cách nào? Và nếu muốn áp dụng đồng thời định dạng đó cho hàng loạt trang web khác nhau thì phải làm sao?

Trả lời khoa học: Để áp dụng cho toàn bộ tệp HTML, ta sử dụng cách thiết lập CSS trong (Internal CSS) đặt trong thẻ <style> hoặc sử dụng CSS ngoài (External CSS). Để áp dụng đồng thời cho nhiều trang web khác nhau, bắt buộc phải sử dụng cách thiết lập CSS ngoài (External CSS) bằng cách tạo một tệp .css riêng biệt và dùng thẻ <link> để nhúng vào tất cả các trang web cần định dạng.

Bài 14. Định dạng văn bản bằng CSS

1. Định dạng văn bản bằng CSS

Các thuộc tính CSS dùng để định dạng văn bản được chia thành 3 nhóm chính: phông chữ, màu chữ và dòng văn bản.

a) CSS định dạng phông chữ

  • font-family: Chọn phông chữ. Các nhóm phông cơ bản: serif (có chân), sans-serif (không chân), monospace (độ rộng đều), cursive (viết tay), fantasy (trừu tượng). Cú pháp ưu tiên: font-family: "Times New Roman", Times, serif; (Nếu không có phông đầu tiên, trình duyệt sẽ tìm phông tiếp theo).
  • font-size: Chọn cỡ chữ. Đơn vị tuyệt đối (px, pt), đơn vị tương đối (%, em, rem). em là so với cỡ chữ phần tử hiện thời, rem so với phần tử gốc.
  • font-style: Kiểu chữ. Nhận giá trị normal (bình thường), italic (in nghiêng).
  • font-weight: Độ dày nét chữ. Nhận giá trị normal, bold, hoặc giá trị số từ 100 đến 900.

b) CSS định dạng màu chữ

Sử dụng thuộc tính color. Giá trị có thể là tên màu tiếng Anh (black, red, blue...), mã Hex, RGB, HSL. Lưu ý: Kí tự * là bộ chọn đại diện cho tất cả các phần tử HTML trên trang web.

c) CSS định dạng dòng văn bản

  • line-height: Chiều cao dòng. Ví dụ: line-height: 1.5; hoặc line-height: 200%;
  • text-align: Căn lề văn bản. Giá trị: left (trái), right (phải), center (giữa), justify (căn đều hai bên).
  • text-decoration: Trang trí. Giá trị: none, underline (gạch dưới), overline (gạch trên đầu), line-through (gạch ngang chữ).
  • text-indent: Thụt lề dòng đầu tiên (dương: thụt vào, âm: thụt lùi ra ngoài).

2. Tính kế thừa và cách lựa chọn theo thứ tự của CSS

a) Tính kế thừa của CSS

Một mẫu CSS áp dụng cho một phần tử cha thì sẽ tự động được áp dụng cho tất cả các phần tử con, cháu bên trong nó. (Ngoại lệ: Một số thuộc tính không được kế thừa mặc định hoặc có hành vi riêng, ví dụ thẻ a thường không kế thừa màu sắc và gạch chân từ cha).

b) Thứ tự ưu tiên (Cascading - Xếp chồng)

Tính chất "Cascading": Mẫu định dạng được viết cuối cùng (trong mã nguồn hoặc file CSS) sẽ được ưu tiên áp dụng nếu các điều kiện khác (như độ ưu tiên của bộ chọn) ngang nhau.

c) Sử dụng kí hiệu * và !important

  • Kí hiệu * (Universal selector): Có mức độ ưu tiên thấp nhất.
  • Kí hiệu !important: Có mức độ ưu tiên cao nhất tuyệt đối. Nếu một thuộc tính có !important, nó sẽ ghi đè tất cả các quy tắc khác, bất kể vị trí hay độ đặc hiệu của bộ chọn.
Tình huống vận dụng Bài 14 - Tình huống 1

Tình huống: Cho mẫu định dạng CSS sau: p {font-size: 1.2em;} và html {font-size: 100%;}. Ý nghĩa khoa học của hai dòng lệnh này là gì?

Trả lời khoa học: Dòng p {font-size: 1.2em;} thiết lập cho toàn bộ các phần tử đoạn văn <p> có cỡ chữ bằng 1,2 lần cỡ chữ hiện thời của trình duyệt (hoặc của phần tử cha trực tiếp chứa nó). Dòng html {font-size: 100%;} thiết lập cỡ chữ mặc định cho toàn bộ trang web (phần tử gốc) theo đúng chế độ mặc định của trình duyệt (thường là 16px).

Tình huống vận dụng Bài 14 - Tình huống 2

Tình huống: Một đoạn mã CSS được viết như sau: h1 {color: blue; text-align: center !important;} h1 {text-align: left; color: red;}. Khi hiển thị, thẻ h1 sẽ có màu gì và được căn lề như thế nào?

Trả lời khoa học: Kết quả áp dụng cho thẻ h1 sẽ là: Chữ có màu đỏ (red) và được căn lề giữa (center). Về màu sắc, quy tắc color: red được viết sau nên có tính chất xếp chồng (Cascading) ghi đè lên quy tắc màu xanh ở trên. Về căn lề, mặc dù text-align: left viết sau, nhưng text-align: center ở trên có từ khóa !important nên nó chiếm độ ưu tiên cao nhất tuyệt đối.

Bài 15. Tạo màu cho chữ và nền

1. Hệ thống màu của CSS

HTML và CSS hỗ trợ biểu diễn màu sắc thông qua ba cách thông dụng nhất:

  • Sử dụng tên màu (Color Names): Dùng tên tiếng Anh có sẵn như red, green, blue, white, black… Phiên bản CSS3 hỗ trợ khoảng 140 tên màu tiêu chuẩn.
  • Hệ màu RGB (Red - Green - Blue): Mô hình trộn 3 màu cơ bản Đỏ (Red), Lục (Green), Lam (Blue). Cú pháp hàm rgb(r, g, b) với giá trị là số nguyên từ 0 đến 255. Cú pháp Hex (thập lục phân) viết là #rrggbb.
  • Hệ màu HSL (Hue - Saturation - Lightness): Gồm H (Hue - Tông màu từ 0-360 độ), S (Saturation - Độ bão hòa %), L (Lightness - Độ sáng %).

2. Thiết lập màu chữ và màu nền bằng CSS

CSS cung cấp các thuộc tính để định dạng màu sắc cho các thành phần:

  • Màu chữ: Thuộc tính color. Có tính kế thừa sang phần tử con.
  • Màu nền: Thuộc tính background-color.
  • Màu đường viền: Thuộc tính border (bao gồm border-color, border-width, border-style). Thuộc tính này không có tính kế thừa.

3. Thiết lập bộ chọn là tổ hợp các phần tử có quan hệ

CSS cho phép kết hợp các bộ chọn dựa trên mối quan hệ giữa các phần tử trong cây HTML:

Loại quan hệ Ký hiệu Ý nghĩa Ví dụ
Con và cháu (Descendant) E F Chọn tất cả F nằm bên trong E (bất kể cấp độ nào). div p { color: blue; }
Cha con trực tiếp (Child) E > F Chỉ chọn F là con trực tiếp (cấp 1) của E. p > em { color: red; }
Anh em liền kề (Adjacent) E + F Chọn F nằm ngay sau E và có cùng cha. em + strong { color: red; }
Anh em (General Sibling) E ~ F Chọn tất cả F nằm sau E và có cùng cha. em ~ strong { color: red; }
Tình huống vận dụng Bài 15 - Tình huống 1

Tình huống: Trong hệ màu định dạng web RGB, màu trắng và màu đen được biểu diễn như thế nào? Trong hệ màu HSL, tham số nào quyết định màu sắc sẽ biến mất chỉ còn lại màu xám?

Trả lời khoa học: Trong hệ màu RGB, màu trắng được biểu diễn là rgb(255, 255, 255) hoặc #FFFFFF; màu đen là rgb(0, 0, 0) hoặc #000000. Trong hệ màu HSL, tham số S (Saturation - Độ bão hòa) là yếu tố quyết định. Khi S = 0%, màu sắc sẽ bị triệt tiêu hoàn toàn và chỉ trở thành màu xám (tùy thuộc vào mức độ sáng L).

Tình huống vận dụng Bài 15 - Tình huống 2

Tình huống: Sự khác biệt chính giữa bộ chọn E F và E > F là gì? Nếu thiết lập màu chữ cho thẻ <body> thì thẻ <p> bên trong có nhận màu đó không?

Trả lời khoa học: Bộ chọn E F (Con và cháu) áp dụng cho tất cả phần tử F nằm bên trong E, dù ở bất kỳ cấp độ sâu nào. Bộ chọn E > F (Con trực tiếp) nghiêm ngặt hơn, chỉ áp dụng cho phần tử F là con trực tiếp (ngay cấp độ phía dưới) của E. Đối với ý thứ hai, thẻ <p> có nhận màu, vì thuộc tính color có tính kế thừa tự động từ thẻ cha (body) sang thẻ con (nếu thẻ p không được định nghĩa màu riêng).

Bài 16. Định dạng khung

1. Phân loại phần tử khối và nội tuyến

Các phần tử HTML được chia làm hai loại chính dựa trên cách hiển thị mặc định:

  • Phần tử khối (Block level): Luôn bắt đầu trên một dòng mới và chiếm toàn bộ chiều rộng có sẵn của phần tử cha (kéo dài từ trái sang phải). Ví dụ: <h1> đến <h6>, <p>, <div>, <table>, <ul>.
  • Phần tử nội tuyến (Inline level): Không bắt đầu dòng mới, nằm chung dòng với các nội dung khác. Chỉ chiếm chiều rộng vừa đủ với nội dung của nó. Ví dụ: <span>, <a>, <img>, <strong>.

Ta có thể thay đổi cách hiển thị mặc định bằng thuộc tính CSS display (giá trị: block, inline, none).

2. Thiết lập định dạng khung bằng CSS (Box Model)

Mọi phần tử HTML đều có thể được coi là một “chiếc hộp” hình chữ nhật. CSS sử dụng mô hình hộp (Box Model) để định dạng. Các thành phần chính bao gồm:

  • Phần nội dung (Content): Vùng chứa văn bản hoặc hình ảnh. Kích thước xác định bởi width và height.
  • Vùng đệm (Padding): Khoảng cách từ nội dung đến đường viền.
  • Đường viền (Border): Đường bao quanh nội dung và vùng đệm (sử dụng border-width, border-style, border-color).
  • Lề (Margin): Khoảng cách từ đường viền ra đến các phần tử xung quanh.

3. Một số bộ chọn đặc biệt của CSS

  • Bộ chọn lớp (Class Selector): Áp dụng cho một nhóm các phần tử có chung kiểu dáng. Khai báo CSS bắt đầu bằng dấu chấm (Ví dụ: .warning).
  • Bộ chọn định danh (ID Selector): Áp dụng cho duy nhất một phần tử đặc biệt trên trang (không được trùng lặp). Khai báo CSS bắt đầu bằng dấu thăng (Ví dụ: #header-main).
  • Bộ chọn thuộc tính: Chọn các phần tử có chứa một thuộc tính cụ thể (Ví dụ: [href]).
Tình huống vận dụng Bài 16 - Tình huống 1

Tình huống: Trong cấu trúc định dạng khung (Box Model) của một phần tử HTML, lề khung (margin) khác gì với vùng đệm (padding)? Khoảng cách từ vùng văn bản đến đường viền khung thuộc về loại nào?

Trả lời khoa học: Lề khung (margin) là khoảng cách không gian tính từ đường viền đẩy ra các phần tử bên ngoài (nhằm tạo khoảng cách giữa các hộp). Vùng đệm (padding) là khoảng không gian tính từ đường viền ép vào nội dung bên trong (tạo sự thoáng đãng cho hộp). Do đó, khoảng cách từ vùng văn bản bên trong ra đến đường viền khung chính là vùng đệm (padding).

Tình huống vận dụng Bài 16 - Tình huống 2

Tình huống: Nêu sự khác biệt cơ bản giữa thuộc tính định danh (ID) và lớp (Class) của các phần tử HTML? Nêu ý nghĩa của bộ chọn div#bat_dau > p.

Trả lời khoa học: ID (Định danh) dùng để xác định tính độc nhất của một phần tử, mỗi ID chỉ được sử dụng duy nhất một lần trên toàn bộ trang web. Ngược lại, Class (Lớp) dùng để nhóm các phần tử có chung kiểu trình bày, một lớp có thể được gán tái sử dụng cho nhiều phần tử khác nhau. Đối với bộ chọn div#bat_dau > p, bộ chọn này có ý nghĩa là: Chọn tất cả các thẻ <p> là con trực tiếp của thẻ <div> đang sở hữu ID là bat_dau.

Bài 17. Các mức ưu tiên của bộ chọn

1. Kiểu bộ chọn dạng Pseudo-class và Pseudo-element

a) Bộ chọn pseudo-class (Lớp giả)

Là các trạng thái đặc biệt của phần tử HTML (động). Các trạng thái này được coi như có sẵn trong CSS. Cú pháp: :pseudo-class.

  • :link: Liên kết chưa được kích hoạt.
  • :visited: Liên kết đã được kích hoạt một lần.
  • :hover: Trạng thái khi di chuyển con trỏ chuột lên đối tượng.

b) Bộ chọn kiểu pseudo-element (Phần tử giả)

Chỉ một phần (hoặc một thành phần) cấu trúc của phần tử bình thường. Cú pháp: ::pseudo-element.

  • ::first-line: Dòng đầu tiên của đối tượng văn bản.
  • ::first-letter: Kí tự đầu tiên của đối tượng văn bản.
  • ::selection: Phần nội dung đang được người dùng bôi đen.

2. Mức độ ưu tiên khi áp dụng CSS

Khi có nhiều mẫu định dạng cùng áp dụng cho một phần tử, trình duyệt sẽ quyết định mẫu nào được ưu tiên dựa trên các mức sau (từ cao xuống thấp):

  1. !important: Các thuộc tính có từ khoá này có mức ưu tiên cao nhất.
  2. CSS trực tiếp (Inline CSS): Định dạng nằm ngay trong thẻ HTML.
  3. Media Type: Định dạng CSS liên quan đến kích thước thiết bị.
  4. Trọng số CSS (Specificity): Mẫu định dạng có tổng trọng số cao hơn sẽ thắng.
  5. Nguyên tắc thứ tự cuối cùng: Nếu trọng số bằng nhau, định dạng viết sau cùng sẽ được áp dụng.
  6. Kế thừa: Nhận thuộc tính từ phần tử cha.

Cách tính trọng số (Specificity): ID (cộng 100 điểm); Class/Pseudo-class (cộng 10 điểm); Element/Pseudo-element (cộng 1 điểm); kí tự * (0 điểm).

Tình huống vận dụng Bài 17 - Tình huống 1

Tình huống: Sự khác nhau cơ bản giữa Pseudo-class (Lớp giả) và Pseudo-element (Phần tử giả) trong cấu trúc bộ chọn CSS là gì?

Trả lời khoa học: Pseudo-class (Lớp giả, 1 dấu hai chấm) dùng để chọn toàn bộ phần tử nhưng dựa trên trạng thái động của chúng (ví dụ: khi rê chuột, khi nhấp chuột). Pseudo-element (Phần tử giả, 2 dấu hai chấm) lại dùng để chọn và định dạng một cấu trúc phần tử nhỏ lẻ bên trong phần tử gốc (ví dụ: chỉ dòng đầu tiên, chỉ chữ cái đầu tiên) mà không cần phải bổ sung thêm các thẻ HTML thủ công để bọc chúng.

Tình huống vận dụng Bài 17 - Tình huống 2

Tình huống: Hãy giải thích sự khác nhau về ý nghĩa và mức độ ưu tiên giữa hai mẫu định dạng sau: #p123 + p {color : red ;} và h2#p123 + p {color : red ;}

Trả lời khoa học: Mẫu #p123 + p sẽ áp dụng cho các phần tử <p> nằm liền kề ngay sau một phần tử bất kì có mã định danh ID là p123. Trong khi đó, mẫu h2#p123 + p mang tính cụ thể cao hơn (đồng nghĩa với trọng số Specificity cao hơn một chút): Nó bắt buộc phải áp dụng cho thẻ <p> nằm liền kề ngay sau một phần tử <h2>, và bản thân thẻ <h2> này phải sở hữu ID là p123.
